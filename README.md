# D Raghuram — Developer Portfolio

Source code for my personal portfolio website, designed as a fast, single-page showcase with direct access to my resume, flagship engineering work, and contact links.

**Live Site:** [draghuram-portfolio.vercel.app](https://draghuram-portfolio.vercel.app)

## About the Build
- **Pure HTML5 & CSS3:** Crafted in a single self-contained `index.html` file without external CSS libraries or JavaScript frameworks for instant load times and zero dependencies.
- **UI & Design:** Built around a Grey Silver & Sunshine Gold frosted glassmorphism palette with responsive grid layouts and a CSS-only system architecture diagram.
- **Deployment:** Hosted on Vercel with continuous deployment directly from this repository.
